# Public score reference / 公开成绩参照

本图将9个已检索到的外部配置与本地21题抽样并列，表示公开成绩的数值位置。当前点值在所列10项中为第4，仅在全量成绩能维持该点值时成立。公开全局排名和未来全量分数均待验证。此图中的外部成绩来自各自公开报告，未重跑。

各系统使用不同阅读模型、裁判与评分细节。本地抽样是7组各3题，整体准确率20/21，类别权重也与500题不同。

Mastra OM页面的类别正确数为75+116+53+30+67+127=468，类别总数为78+133+56+30+70+133=500，因此本图使用93.6%逐题准确率；其94.87%为六类百分比的宏平均，原值在数据文件保留。agentmemory V4公开README标为oracle dataset，因此从本图的S参照中排除。更多公开系统存在，本图范围固定为已列出的9个配置。
